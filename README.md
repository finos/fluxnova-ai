# Fluxnova AI

## Overview

This repository was originally established to host AI-related plugins for the Fluxnova project. Following a subsequent architectural decision, all AI-specific plugin development has been consolidated into the [fluxnova-plugins](https://github.com/finos/fluxnova-plugins) repository. This consolidation was undertaken to simplify the overall project structure and to align AI plugin development with the established patterns, conventions, and methodology already in place within that repository.

As a result, all documentation, source code, and contribution activity relating to Fluxnova AI plugins can be found in the **fluxnova-plugins** repository.

## Issues & Discussions

This repository remains active for the purposes of community engagement. The **Issues** and **Discussions** tabs are available and encouraged for their intended use — please feel free to raise questions, report bugs, propose ideas, or engage in broader conversations here.

## Contributing

For any questions, bugs, or feature requests related to Fluxnova AI plugins, please refer to the [fluxnova-plugins repository](https://github.com/finos/fluxnova-plugins).

For anything else, please open an [issue](https://github.com/finos/fluxnova-ai/issues) in this repository or send an email to the project mailing list.

_NOTE:_ Commits and pull requests to FINOS repositories will only be accepted from those contributors with an active, executed Individual Contributor License Agreement (ICLA) with FINOS OR who are covered under an existing and active Corporate Contribution License Agreement (CCLA) executed with FINOS. Commits from individuals not covered under an ICLA or CCLA will be flagged and blocked by the FINOS Clabot tool (or [EasyCLA](https://community.finos.org/docs/governance/Software-Projects/easycla)). Please note that some CCLAs require individuals/employees to be explicitly named on the CCLA.

*Need an ICLA? Unsure if you are covered under an existing CCLA? Email [help@finos.org](mailto:help@finos.org)*
